# SayBop visual identity — BlazeDevStudio v3

The owner-approved current brand master is in the private [BlazeDevStudio Drive folder](https://drive.google.com/drive/folders/10L7iVO2U2FLteckOkRtO6HqGhSPLPMdb) and website source [branding v3](https://github.com/BlazeDevStudio/BlazeDevStudio.github.io/tree/main/assets/branding/v3).

This project uses the approved **B** silhouette, not the auxiliary Z (reserved for CDN/dependencies). The shipped Android VectorDrawable preserves the B path geometry from `Blaze_B_approved_target_VECTOR.svg`, but uses flat brand colors, a simplified ruby target ring, and a native vector background for scalable small-screen rendering. It is a launcher adaptation, not a replacement for the 8K approved master. No proprietary Ditty art is used.

Palette: midnight #090F1D, off-white #F4F7FF, blue #1671E6 / #53A7FF, ruby accent #F10843.

UI: SayBop retains its own name and product personality; publisher branding appears as the v3 B next to the product title and as launcher icon. For any future high-resolution marketing assets, start from the original master in Drive, not from this flat-color Android adaptation.
